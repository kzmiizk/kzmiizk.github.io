リサーチ・情報設計・ワイヤーフレームから、プラットフォーム全体のUIデザインを担当しました。

02 / UI DESIGN

新規サービスのUI制作

初めてWeb3に触れる人にも親しみやすい印象を目指し、白を基調に丸みのある造形で制作しました。
ダーク版とホワイト版を比較して提示し、チームとデザイン方針をすり合わせました。

※元のFigmaを複製し、掲載用のゲーム画像・例文だけを補完しています。記事の日付・数値・広告枠は設計時のサンプルです。長い画面は冒頭を抜粋し、元資料は保持しています。

03 / COMPONENTS

UIコンポーネントの作成

検索・カード・リストなどのUI部品と、操作状態ごとのバリエーション。

04 / CHARACTER

キャラクターデザイン

Web3の解説コンテンツに用いるクマの3DキャラクターをBlenderで制作。キャラクターを使った紹介方法を提案しました。
